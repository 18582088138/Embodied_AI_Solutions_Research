# 分项版本管理

本仓库将 `类别/分项`（例如 `01_Compute_Chips/01_NVIDIA`）作为一次完成提交的单位。用户已授权本项目 push 与 branch 管理；授权不替代研究范围或用户审阅状态。

每个分项完成适用章节、必要专题、原件归档、事实/图像复核和结构检查后，更新分项 README 与 progress.json。报告和导航使用相对链接；工具 JSON 使用仓库根相对路径。原件日期和历史基线保持原样。

运行根目录 `toolkit/organize_repository.py --build-indexes` 检查导航。暂存仅该分项的报告、正文图表、来源清单与状态（完整原件留本地），审阅暂存区，提交 `research(类别/分项): <具体成果>`，随后 fetch/push 当前适用分支。公共 skill、工具和根目录导航另作提交。

未完成分项需要备份时，在工作分支明确标注 WIP，不声称研究完成。并行用户修改与远端历史必须保留，默认不 force push。完整原件和网页依赖通过 .gitignore 留本地；不上传 Git LFS；上传失败或配额限制须如实记录，不能声称已推送成功。
