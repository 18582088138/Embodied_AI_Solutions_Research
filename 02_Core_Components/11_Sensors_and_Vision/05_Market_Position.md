# 传感器与视觉：奥比中光、柯力传感、速腾聚创 — 市场地位

调研日期：2026-11-03（Asia/Shanghai）｜版本：首轮公开资料研究｜结论状态：含未披露/待验证项

## 研究发现

### 本轮能确认的生态
奥比中光有产品规格、SDK 与 ROS 2 包；速腾聚创有 LiDAR SDK 和 AC1 新产品路线；柯力传感的具体机器人产品/份额尚缺公开可读证据。[orbbec-gemini335](#orbbec-gemini335)[orbbec-sdk](#orbbec-sdk)[robosense-driver](#robosense-driver)[robosense-ac1](#robosense-ac1)
### 未披露数据
没有同口径 2025–2026 年机器人相机、机器人 LiDAR、六维力市场份额。车载 LiDAR 出货量、消费深度相机出货量、称重传感器份额不能转成具身供应份额。客户合作新闻不必然表明量产订单或独家供货。
### 供应链建议
将传感芯片/ASIC、激光器、CMOS、IMU、光学、固件和接口板分别做国产化核验；按量产供货、校准一致性、寿命、维修与数据许可比较成本。现阶段对奥比/速腾的软件可获得性有较强证据，但不能据此判断市占率。
