# 灵巧手与微型传动：兆威机电、因时机器人、强脑科技 — 市场地位

调研日期：2026-11-03（Asia/Shanghai）｜版本：首轮公开资料研究｜结论状态：含未披露/待验证项

## 研究发现

### 本轮判断
因时已提供详细手部型号规格；兆威的微型传动与强脑的仿生手/BCI 产品线是可追溯的研究入口。公开规格完善度与供应份额不是同一指标。[inspire-rh56](#inspire-rh56)[zhaowei](#zhaowei)[brainco](#brainco)
### 商业证据缺口
本轮未核验三家 2025–2026 年机器人灵巧手实际交付量、独家客户、良率、产能利用率、售价与国产替代率。医疗/康复仿生手与工业机器人灵巧手的收入和认证不能混用。
### 采购建议
按单手价、寿命、备件、指尖维护、机械一致性、驱动许可和校准成本询价；分别列微型电机、齿轮、编码器、触觉器件与控制器来源。订单、产能和已交付需要不同证据，不根据展示合作名单推断量产供货。
