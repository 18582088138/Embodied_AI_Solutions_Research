## 资料与使用

每个产品独立保存报告、来源清单与研究状态；HTML/PDF原件和依赖留在其本地reference_metrial/，不上传Git。清单保留真实采集时间、URL、SHA256、失败候选和依赖缺失。首轮报告可用于研究导航与PoC候选筛选；报价、完整许可和实机性能按报告中的缺口继续核验。
